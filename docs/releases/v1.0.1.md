# tdt-media-stream v1.0.1

WebSocket 直播与 WebRTC 现在使用相同的发送队列策略。单个观看者的队列满时，服务端丢弃新到的帧并记录丢帧数，在原连接上继续发送已排队的帧。队列腾出空间后恢复接收新帧。若丢失参考帧，画面可能要到下一关键帧才恢复。单次网络写入超过 `writeTimeout` 时会关闭连接。

## Docker 升级

Linux AMD64 和 ARM64 使用同一镜像地址。

```sh
docker pull ghcr.io/zqhhh77/tdt-media-stream:1.0.1
```

使用 Compose 时，将现有服务的 `image` 更新为上述版本，保留当前的端口、配置文件和挂载，然后运行 `docker compose up -d tdt-media-stream`。
